# SplitLane 0.5.1 (beta)

[English](#english) · [Русский](#русский)

## English

SplitLane 0.5.1 fixes a start-up that hung for as long as the Tailscale app stayed disconnected, and a "Turn on split routing at startup" that did nothing after such a start. Install it over 0.5.0, or let SplitLane update itself; split routing and your servers stay as they were.

### What changed

- **No hang with the Tailscale app disconnected.** When split routing is turned on, SplitLane turns off the exit node of the Tailscale app and turns it back on later. If you disconnected the Tailscale app in the meantime and shut the PC down, SplitLane stayed in **Turning off…** after the next sign-in, with "Can't turn the exit node back on in the Tailscale app", until you connected the Tailscale app or chose **Turn off without restoring**. While it waited, no program used the VPN. A disconnected Tailscale app never reports an exit node, although the setting was already back. SplitLane now checks the setting itself and goes on; the exit node works again when you connect the Tailscale app. The same holds when you turn split routing off while the Tailscale app is disconnected.
- **"Turn on split routing at startup" is not lost.** A window started at sign-in could connect while SplitLane was still turning the exit node of the Tailscale app back on, and the setting then did nothing until the next start. The window now waits for that to finish, up to 2 minutes, and turns split routing on.

Only PCs with the Tailscale app installed are affected.

Download `SplitLane-Setup-0.5.1.exe` and `SplitLane-Setup-0.5.1.exe.sha256` below and verify the download as described in the [0.3.0 notes](https://github.com/splitlane-app/splitlane/blob/main/docs/release-notes/0.3.0.md), or use **Check for updates**. ## Русский

SplitLane 0.5.1 исправляет зависание при старте, которое длилось, пока приложение Tailscale оставалось отключённым, и настройку «Включать деление при запуске», которая после такого старта не срабатывала. Ставьте поверх 0.5.0 или обновитесь из самого SplitLane; деление и ваши серверы остаются, как были.

### Что изменилось

- **Нет зависания при отключённом приложении Tailscale.** При включении деления SplitLane выключает exit node в приложении Tailscale, а позже возвращает его. Если за это время вы отключили приложение Tailscale и выключили компьютер, после следующего входа в Windows SplitLane оставался в состоянии «Выключается…» с сообщением «Не удаётся вернуть exit node в приложении Tailscale», пока вы не подключали приложение Tailscale или не нажимали «Выключить без возврата». Всё это время ни одна программа не шла через VPN. Отключённое приложение Tailscale не сообщает об exit node, хотя настройка уже была возвращена. Теперь SplitLane проверяет саму настройку и продолжает работу; exit node снова заработает, когда вы подключите приложение Tailscale. То же относится к выключению деления при отключённом приложении Tailscale.
- **«Включать деление при запуске» не теряется.** Окно, запущенное при входе в Windows, могло подключиться, пока SplitLane ещё возвращал exit node приложения Tailscale, и тогда настройка не срабатывала до следующего запуска. Теперь окно ждёт окончания возврата, не дольше 2 минут, и включает деление.

Ошибки касались только компьютеров, где установлено приложение Tailscale.
