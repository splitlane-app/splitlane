# SplitLane 0.3.0 (beta)

[English](#english) · [Русский](#русский)

## English

SplitLane 0.3.0 is the first public beta. SplitLane puts programs on two lanes on Windows 10/11 x64: programs on **Via VPN** go through your Tailscale exit node, the rest goes **Direct** through your normal connection. It works with Tailscale only.

### Highlights

- **Two lanes.** Via VPN and Direct, with a main lane for the programs you haven't pinned. Switching the main lane moves them all at once.
- **Drag and drop.** Move cards between the lanes, drop `.exe` files and shortcuts from Explorer, or add a program that is online now, an installed program or a file. A program means its whole folder by default, so its updaters go the same way.
- **Live activity.** Speed per program and per lane, and the current connections of a program in its card.
- **Installer with the service.** One UAC prompt installs SplitLane for all users in `%ProgramFiles%\SplitLane` and sets up the background service, which restarts itself after a crash. The installer and the uninstaller turn the exit node of the Tailscale app back on before they change anything.
- **In-app updates.** SplitLane checks GitHub Releases, downloads the new installer, checks its SHA-256 and installs it after you confirm the Windows prompt. Split routing stays as it was.
- **English and Russian.** The window, the tray menu, the installer and the uninstaller follow the language of Windows; the window has a language selector on the **Connection** screen.

### Requirements

- Windows 10 or 11, x64.
- Tailscale for Windows, installed and logged in, and an exit node in your tailnet that you can use.
- A Windows account with administrator rights; you install and use SplitLane under the same account.

### Install

1. Download `SplitLane-Setup-0.3.0.exe` and `SplitLane-Setup-0.3.0.exe.sha256` below.
2. Verify the download in PowerShell, in the folder with both files:

   ```powershell
   $file = 'SplitLane-Setup-0.3.0.exe'
   $expected = (-split (Get-Content "$file.sha256" -Raw))[0]
   (Get-FileHash $file -Algorithm SHA256).Hash -eq $expected
   ```

   `True` means the file matches the checksum.
3. Run the installer. It isn't signed yet, so SmartScreen shows "Windows protected your PC": click **More info**, then **Run anyway**.
4. In the window, click **Log in to Tailscale** and log in in your browser, choose an exit node, click **Turn on split routing** and drag programs onto the lanes.

The full guide is in the [README](https://github.com/splitlane-app/splitlane#readme).

### Known limitations

- The installer and the programs aren't signed: SmartScreen warns about the installer, and the update check verifies integrity, not authenticity.
- One Windows user per PC.
- Tailscale only.
- Installation only in `%ProgramFiles%\SplitLane`.
- The embedded node is a separate device in your tailnet, `<PC name>-splitlane`, with its own login expiry. Uninstalling doesn't remove it; remove it in the Tailscale admin console.
- DNS is shared by both lanes; MagicDNS names don't resolve while split routing is on if the Tailscale app manages DNS.
- WSL and virtual machines follow the main lane. IPv6 to the internet doesn't work while split routing is on. There is no kill switch.

The full list is in the README, section "Known limitations of this beta".

### Privacy

No telemetry and no accounts of its own. The window checks GitHub for updates, the embedded node talks to Tailscale, and while split routing is on the service checks both lanes with `api.ipify.org`. Details: [PRIVACY.md](https://github.com/splitlane-app/splitlane/blob/main/PRIVACY.md).

### Reporting problems

Open an issue: <https://github.com/splitlane-app/splitlane/issues>. Include the versions from the **Connection** screen, the Windows version, the Tailscale version and what you did. If split routing doesn't turn on, **Save log** on the banner creates a diagnostics archive; it contains the paths of your programs and the names of your exit nodes, so look through it before you attach it. Report security problems privately, as described in [SECURITY.md](https://github.com/splitlane-app/splitlane/blob/main/SECURITY.md).

## Русский

SplitLane 0.3.0 — первая открытая бета-версия. SplitLane раскладывает программы на Windows 10/11 x64 по двум дорожкам: программы дорожки «Через VPN» идут через ваш exit node Tailscale, остальные — «Напрямую», через обычное подключение. Работает только с Tailscale.

### Главное

- **Две дорожки.** «Через VPN» и «Напрямую» и основная дорожка для программ, которые вы не закрепили. Смена основной дорожки переносит их все сразу.
- **Перетаскивание.** Карточки переносятся между дорожками, файлы `.exe` и ярлыки — из Проводника, а через «+ Добавить» — программы, которые сейчас в сети, установленные программы или выбранный файл. По умолчанию программа — это вся её папка, поэтому обновлялки идут той же дорожкой.
- **Живая активность.** Скорость по программам и дорожкам и текущие соединения программы в её карточке.
- **Установщик со службой.** Один запрос UAC — и SplitLane установлен для всех пользователей в `%ProgramFiles%\SplitLane`, а фоновая служба настроена; после сбоя она перезапускается сама. Установщик и деинсталлятор включают exit node приложения Tailscale обратно, прежде чем что-то менять.
- **Обновления в приложении.** SplitLane проверяет GitHub Releases, скачивает новый установщик, сверяет его SHA-256 и ставит после подтверждения в запросе Windows. Деление остаётся, как было.
- **Русский и английский.** Окно, меню значка, установщик и деинсталлятор говорят на языке Windows; в окне язык выбирается на экране «Подключение».

### Что нужно

- Windows 10 или 11, x64.
- Tailscale для Windows, установленный и с выполненным входом, и exit node в вашей сети Tailscale, которым вам можно пользоваться.
- Учётная запись Windows с правами администратора; SplitLane устанавливают и используют под одной и той же учётной записью.

### Установка

1. Скачайте ниже `SplitLane-Setup-0.3.0.exe` и `SplitLane-Setup-0.3.0.exe.sha256`.
2. Проверьте загрузку в PowerShell, в папке с обоими файлами:

   ```powershell
   $file = 'SplitLane-Setup-0.3.0.exe'
   $expected = (-split (Get-Content "$file.sha256" -Raw))[0]
   (Get-FileHash $file -Algorithm SHA256).Hash -eq $expected
   ```

   `True` значит, что файл совпадает с контрольной суммой.
3. Запустите установщик. Он пока не подписан, поэтому SmartScreen показывает «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
4. В окне нажмите «Войти в Tailscale» и войдите в браузере, выберите exit node, нажмите «Включить деление» и разложите программы по дорожкам.

Полное описание — в [README](https://github.com/splitlane-app/splitlane/blob/main/README.ru.md).

### Известные ограничения

- Установщик и программы не подписаны: SmartScreen предупреждает об установщике, а проверка обновлений подтверждает целостность, но не подлинность.
- Один пользователь Windows на компьютер.
- Только Tailscale.
- Установка только в `%ProgramFiles%\SplitLane`.
- Встроенный узел — отдельное устройство в сети Tailscale, `<имя ПК>-splitlane`, со своим сроком действия входа. Удаление программы его не убирает; удалите его в консоли администратора Tailscale.
- DNS общий для обеих дорожек; если приложение Tailscale управляет DNS, имена MagicDNS не разрешаются, пока деление включено.
- Трафик WSL и виртуальных машин идёт по основной дорожке. IPv6 в интернет не работает, пока деление включено. Блокировки на случай сбоя нет.

Полный список — в README, раздел «Известные ограничения беты».

### Конфиденциальность

Нет телеметрии и собственных учётных записей. Окно проверяет обновления на GitHub, встроенный узел обращается к Tailscale, а пока деление включено, служба проверяет обе дорожки через `api.ipify.org`. Подробно: [PRIVACY.md](https://github.com/splitlane-app/splitlane/blob/main/PRIVACY.md#русский).

### Если что-то не работает

Создайте issue: <https://github.com/splitlane-app/splitlane/issues>. Укажите версии с экрана «Подключение», версию Windows, версию Tailscale и что вы делали. Если деление не включается, кнопка «Сохранить журнал» на плашке создаёт архив диагностики; в нём есть пути ваших программ и имена ваших exit node, поэтому просмотрите его, прежде чем прикладывать. Об уязвимостях сообщайте закрыто, как описано в [SECURITY.md](https://github.com/splitlane-app/splitlane/blob/main/SECURITY.md).
