# Release notes

Every release note in this folder ends with a line that links to the code signing policy. Use this line exactly.

English:

```
[Code signing policy](https://github.com/splitlane-app/splitlane/blob/main/CODE_SIGNING_POLICY.md)
```

Русский:

```
[Политика подписи (Code signing policy)](https://github.com/splitlane-app/splitlane/blob/main/CODE_SIGNING_POLICY.md)
```

In a note with both languages, the English line ends the English part and the Russian line ends the Russian part. The notes of versions already published (up to 0.5.0) are not changed.
