# SplitLane 0.3.1 (beta)

[English](#english) · [Русский](#русский)

## English

SplitLane 0.3.1 fixes the rough edges of the **Connection** screen found in the first beta sessions and adds notifications for the times when the window is in the tray. Install it over 0.3.0, or let SplitLane update itself; split routing stays as it was.

### What changed

- **Back at the top.** **Back to lanes** is now the first control of the **Connection** screen, and **Esc** does the same (an open drop-down list keeps the key).
- **Exit node as a real list.** The exit node is one group of options with a mark on the chosen node and **offline** on the nodes that are off. The arrow keys move through it; a choice is sent when you stop moving, so one pass over the list restarts split routing once, not once per key.
- **Update from the Connection screen.** Next to "Version X is available" there are now the same buttons as in the banner: **Update**, and **Retry** after a refusal or a failed download.
- **The success notice closes itself.** "SplitLane was updated to X" has a small close icon and goes away after 10 seconds.
- **The exit node's name in the header.** While split routing is off, the header shows the last name SplitLane saw for the node, not its address (the address only if the name was never seen).
- **Notifications.** While the window is in the tray, SplitLane shows a Windows notification when split routing stops with an error, when the VPN server can't be reached, when the Tailscale app turns its exit node back on, when the Tailscale login expires, and when a new version is available. Each is shown once when it starts, with a quiet period of 10 minutes for the same kind; clicking it opens the window. Turn them off with **Show notifications** on the **Connection** screen.

### Install and update

Download `SplitLane-Setup-0.3.1.exe` and `SplitLane-Setup-0.3.1.exe.sha256` below and verify the download as described in the [0.3.0 notes](0.3.0.md), or use **Check for updates**. Known limitations are the same as in 0.3.0; the full list is in the [README](https://github.com/splitlane-app/splitlane#readme).

### Reporting problems

Open an issue: <https://github.com/splitlane-app/splitlane/issues>. Include the versions from the **Connection** screen and what you did. Report security problems privately, as described in [SECURITY.md](https://github.com/splitlane-app/splitlane/blob/main/SECURITY.md).

## Русский

SplitLane 0.3.1 исправляет шероховатости экрана «Подключение», найденные в первых сессиях беты, и добавляет уведомления на то время, когда окно свёрнуто в значок. Ставьте поверх 0.3.0 или обновитесь из самого SplitLane; деление остаётся, как было.

### Что изменилось

- **«Назад» вверху.** «Назад к дорожкам» теперь первый элемент экрана «Подключение», и **Esc** делает то же (открытый выпадающий список оставляет клавишу себе).
- **Exit node как настоящий список.** Exit node — одна группа вариантов с отметкой выбранного узла и словами «не в сети» у выключенных. Стрелки перемещают по списку; выбор отправляется, когда вы перестали двигаться, поэтому один проход по списку перезапускает деление один раз, а не на каждую клавишу.
- **Обновление с экрана «Подключение».** Рядом с «Доступна версия X» теперь те же кнопки, что и в плашке: «Обновить», а после отказа или неудачной загрузки — «Повторить».
- **Сообщение об успехе закрывается само.** У «SplitLane обновлён до X» есть маленький значок закрытия, и оно исчезает через 10 секунд.
- **Имя exit node в шапке.** Пока деление выключено, в шапке стоит последнее имя узла, которое видел SplitLane, а не его адрес (адрес — только если имя ни разу не было видно).
- **Уведомления.** Пока окно свёрнуто в значок, SplitLane показывает уведомление Windows, когда деление остановилось с ошибкой, когда нет связи с VPN-сервером, когда приложение Tailscale снова включило exit node, когда истёк вход в Tailscale и когда вышла новая версия. Каждое показывается один раз в начале, а такое же уведомление повторится не раньше чем через 10 минут; щелчок открывает окно. Отключаются настройкой «Показывать уведомления» на экране «Подключение».

### Установка и обновление

Скачайте ниже `SplitLane-Setup-0.3.1.exe` и `SplitLane-Setup-0.3.1.exe.sha256` и проверьте загрузку, как описано в [заметках 0.3.0](0.3.0.md), или нажмите «Проверить обновления». Известные ограничения те же, что в 0.3.0; полный список — в [README](https://github.com/splitlane-app/splitlane/blob/main/README.ru.md).

### Если что-то не работает

Создайте issue: <https://github.com/splitlane-app/splitlane/issues>. Укажите версии с экрана «Подключение» и что вы делали. Об уязвимостях сообщайте закрыто, как описано в [SECURITY.md](https://github.com/splitlane-app/splitlane/blob/main/SECURITY.md).
