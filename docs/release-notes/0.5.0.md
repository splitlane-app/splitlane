# SplitLane 0.5.0 (beta)

[English](#english) · [Русский](#русский)

## English

SplitLane 0.5.0 sets up your own VPN server for you. Rent a VPS, type its address, login and password (or pick its SSH key), click **Set up** — SplitLane installs the server over SSH, adds it and selects it, and gives you a QR code for your phone. Install it over 0.4.0, or let SplitLane update itself; split routing and your servers stay as they were.

### What's new

- **Your own VPS.** A fourth way to connect on **Connect a VPN** and **Connection**. SplitLane connects over SSH, checks the system (Debian 12 or later, Ubuntu 22.04 or later), installs VLESS + Reality and Hysteria2 with a subscription, and shows each step as it goes. The servers appear in the list and the first one leads the VPN lane. Setting up the same server again keeps its keys.
- **Light protection for the server.** The setup also installs fail2ban, which blocks addresses that keep guessing the SSH password (the addresses connected during the setup are exempt), and turns on automatic security updates. It doesn't change how you log in.
- **Connect a phone.** Every subscription on **Connection** has **Connect a phone**: a QR code of the subscription for Hiddify or v2rayNG. The code is a secret — whoever sees it gets your VPN.
- **Credentials are used once.** The password or the key goes to the server only for the setup and is never stored, logged or sent to SplitLane's service; closing the window or leaving the screen drops it.
- **Clear errors.** A wrong login, a server that accepts only keys, a provider that forces a password change, an unsupported system, closed ports — each gets its own explanation. If your internet provider blocks the server's address or its protocol, the error says so and suggests what helps.
- **The server kit** (`scripts/server`) gained the options this needs: machine-readable output, the choice of protocols, automatic ports when 443 is taken, and the light protection. A setup that is cancelled or loses its connection finishes on the server, and the next run picks up the result.

### Install and update

Download `SplitLane-Setup-0.5.0.exe` and `SplitLane-Setup-0.5.0.exe.sha256` below and verify the download as described in the [0.3.0 notes](https://github.com/splitlane-app/splitlane/blob/main/docs/release-notes/0.3.0.md), or use **Check for updates**. Known limits of the VPS setup — the server's host key isn't verified at the first connection, access isn't remembered, Ubuntu 22.04 has no package for the subscription's web server — are in the [README](https://github.com/splitlane-app/splitlane#readme).

### Reporting problems

Open an issue: <https://github.com/splitlane-app/splitlane/issues>. Include the versions from the **Connection** screen and what you did, but never a password, a key, a link or a subscription address. Report security problems privately, as described in [SECURITY.md](https://github.com/splitlane-app/splitlane/blob/main/SECURITY.md).

## Русский

SplitLane 0.5.0 сам ставит вам собственный VPN-сервер. Арендуйте VPS, введите его адрес, логин и пароль (или выберите SSH-ключ), нажмите «Настроить» — SplitLane по SSH установит сервер, добавит и выберет его и даст QR-код для телефона. Ставьте поверх 0.4.0 или обновитесь из самого SplitLane; деление и ваши серверы остаются, как были.

### Что нового

- **Свой VPS.** Четвёртый способ подключения на экранах «Подключите VPN» и «Подключение». SplitLane подключается по SSH, проверяет систему (Debian 12 и новее, Ubuntu 22.04 и новее), ставит VLESS + Reality и Hysteria2 с подпиской и показывает каждый шаг. Серверы появляются в списке, первый ведёт дорожку VPN. Повторная настройка того же сервера сохраняет его ключи.
- **Лёгкая защита сервера.** Заодно ставится fail2ban — он блокирует адреса, которые подбирают пароль SSH (адреса, подключённые во время настройки, не блокируются), — и включаются автоматические обновления безопасности. Способ входа на сервер не меняется.
- **Подключить телефон.** У каждой подписки в «Подключении» есть «Подключить телефон»: QR-код подписки для Hiddify или v2rayNG. Код — секрет: кто его увидит, получит доступ к вашему VPN.
- **Данные для входа — один раз.** Пароль или ключ уходят на сервер только на время настройки и нигде не сохраняются, не пишутся в журналы и не попадают в службу SplitLane; закрытие окна или уход с экрана их забывает.
- **Понятные ошибки.** Неверный логин, сервер только для входа по ключу, хостинг, который требует сменить пароль, неподходящая система, закрытые порты — у каждой своя подсказка. Если провайдер блокирует адрес сервера или его протокол, сообщение об ошибке говорит и об этом и подсказывает, что поможет.
- **Набор для сервера** (`scripts/server`) получил то, что для этого нужно: машинный вывод, выбор протоколов, автоматические порты, когда 443 занят, и лёгкую защиту. Настройка, которую отменили или у которой оборвалась связь, доходит на сервере до конца, а следующий запуск забирает итог.

### Установка и обновление

Скачайте ниже `SplitLane-Setup-0.5.0.exe` и `SplitLane-Setup-0.5.0.exe.sha256` и проверьте загрузку, как описано в [заметках 0.3.0](https://github.com/splitlane-app/splitlane/blob/main/docs/release-notes/0.3.0.md), или нажмите «Проверить обновления». Известные ограничения настройки VPS — ключ сервера при первом подключении не проверяется, доступ не запоминается, в Ubuntu 22.04 нет пакета веб-сервера для подписки — в [README](https://github.com/splitlane-app/splitlane/blob/main/README.ru.md).

### Если что-то не работает

Создайте issue: <https://github.com/splitlane-app/splitlane/issues>. Укажите версии с экрана «Подключение» и что вы делали, но никогда не прикладывайте пароль, ключ, ссылку или адрес подписки. Об уязвимостях сообщайте закрыто, как описано в [SECURITY.md](https://github.com/splitlane-app/splitlane/blob/main/SECURITY.md).
