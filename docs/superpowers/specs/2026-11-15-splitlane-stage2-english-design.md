# SplitLane, этап 2, часть 3: английский интерфейс

Дата: 2026-11-15. Статус: решения приняты исполнителем по поручению владельца продукта («продолжай»; порядок частей этапа 2 согласован раньше).

Основа — спецификации частей 1 и 2 этапа 2 и спецификация этапа 1. Здесь — только то, что меняется.

## 1. Зачем и что входит

Открытый выпуск (часть 4) — для всех желающих, поэтому окно, меню значка, установщик и деинсталлятор говорят по-английски, если Windows не русская. Русский остаётся полным и основным для русской Windows.

Не входит: другие языки, кроме русского и английского; перевод README и страниц выпуска (часть 4); перевод текстов служебного процесса (его строки в журнале и `-REFUSED` остаются английскими).

## 2. Выбор языка

- Языки: `ru` и `en`.
- По умолчанию — язык Windows: первый язык из `app.getPreferredSystemLanguages()`; начинается с `ru` → русский, иначе английский. Пустой список — английский.
- Настройка окна «Язык» (`language`: `system` | `ru` | `en`, по умолчанию `system`) на экране «Подключение» рядом с прочими настройками: «Как в Windows», «Русский», «English» (названия языков всегда на своём языке). Смена применяется сразу: страница перерисовывается, меню значка пересобирается, `lang` документа меняется.

## 3. Окно

- Словарь `en.ts` с теми же ключами, что `ru.ts`; полнота проверяется типом (у каждого языка — все ключи) и тестом (одинаковые параметры `{…}` в строках обоих языков).
- `t()` берёт строку текущего языка. Текущий язык страница получает в снимке (`Snapshot.language: 'ru' | 'en'` — уже разрешённый из настройки и системы).
- Числа: десятичный разделитель — запятая в русском, точка в английском; единицы скорости — из словаря. Сортировка списков программ — `localeCompare` с текущим языком.
- Причины ошибок механизма обновлений (английский текст из основного процесса, часть 2) показываются переведёнными: известные причины сопоставляются с ключами словаря (`update.reason.*`), неизвестные — как есть.
- Тексты основного процесса (меню значка, фильтры диалогов, подсказка значка) — словарь основного процесса с двумя языками; язык — тот же разрешённый.

## 4. Установщик и деинсталлятор

- Два языка мастера: русский и английский; язык выбирается автоматически по языку Windows (русский — если язык интерфейса Windows русский, иначе английский), без окна выбора языка.
- Свои тексты `installer.nsh` (подготовка, отказы, страница удаления, сообщения) — через `LangString` для обоих языков.
- Тихий режим не меняется.

## 5. Проверка

- Модульные тесты: полнота и параметры словарей; выбор языка (система `ru-RU`, `ru`, `en-US`, `de-DE`, пусто; настройка поверх системы); форматирование чисел в обоих языках; перевод причин обновлений; смена языка перерисовывает страницу и меню значка; `lang` документа.
- Сборка установщика на GitHub Actions (тихий режим) — зелёная; оба языка компилируются.
- Живая проверка на ПК владельца (без сторожа: сеть не меняется): переключение языка в окне туда и обратно, меню значка, экраны настройки, доски, «Подключение»; английский установщик — на чистой виртуальной машине в части 4.

## 6. Известные ограничения части 3

- Строки служебного процесса (журнал, причины отказов `install`/`prepare`/`uninstall` в окне мастера) — английские в обоих языках.
- Причины, которых нет в словаре обновлений, показываются по-английски.
